# Карта REST API MVP

Базовый URL: `/api/v1`. Все даты и время передаются в ISO-8601 с offset, например `2026-11-02T10:00:00+03:00`. Окончательный контракт реализуется по лабораторным 2–5.

## Роли и статусы

- Роли: `EMPLOYEE`, `ADMIN`.
- Статусы брони: `PENDING`, `CONFIRMED`, `REJECTED`, `CANCELLED`, `COMPLETED`.

## Endpoint-карта

| Функция | Метод и путь | Доступ |
|---|---|---|
| Регистрация | `POST /auth/register` | Публичный |
| Вход | `POST /auth/login` | Публичный |
| Список комнат и фильтры | `GET /rooms?capacity=&equipment=&from=&to=` | Авторизованный пользователь |
| Создать бронь | `POST /bookings` | `EMPLOYEE` |
| Отменить бронь | `PATCH /bookings/{id}/cancel` | Владелец брони |
| Мои брони | `GET /bookings/me?scope=active|history` | `EMPLOYEE` |
| Добавить комнату | `POST /admin/rooms` | `ADMIN` |
| Редактировать комнату | `PUT /admin/rooms/{id}` | `ADMIN` |
| Архивировать комнату | `PATCH /admin/rooms/{id}/archive` | `ADMIN` |
| Список заявок | `GET /admin/bookings?status=PENDING` | `ADMIN` |
| Подтвердить бронь | `PATCH /admin/bookings/{id}/confirm` | `ADMIN` |
| Отклонить бронь | `PATCH /admin/bookings/{id}/reject` | `ADMIN` |
| Оставить отзыв | `POST /rooms/{roomId}/reviews` | Автор подтверждённой завершённой брони |

## Бизнес-правила

1. Комната не может иметь пересекающиеся брони со статусом `PENDING` или `CONFIRMED`.
2. Время окончания должно быть позже времени начала.
3. Сотрудник отменяет только собственную бронь; подтверждённую бронь нельзя отменять после её начала.
4. Архивная комната не показывается в поиске и не доступна для новых бронирований.
5. Один пользователь оставляет не более одного отзыва на завершённую подтверждённую бронь.
