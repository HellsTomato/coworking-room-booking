# Паспорт проекта

## 1. Название и назначение

**Coworking Room Booking System** — новый проект для бронирования переговорных комнат коворкинга. Он заменяет ручные записи в чатах и таблицах, снижая риск двойного бронирования и потери истории заявок.

## 2. Пользователи и роли

| Роль | Возможности |
|---|---|
| `EMPLOYEE` | Регистрация и вход, поиск комнат, создание и отмена собственной брони, просмотр истории, отзыв после подтверждённой брони |
| `ADMIN` | Управление комнатами, подтверждение и отклонение заявок |

## 3. Функции MVP

1. Регистрация и вход с JWT.
2. Поиск комнат по вместимости, оборудованию и доступности.
3. Создание, отмена и просмотр бронирований.
4. Управление комнатами и решения по заявкам администратора.
5. Отзывы после подтверждённого бронирования.

## 4. Стек

| Часть | Технологии |
|---|---|
| Frontend | JavaScript, React, React Router, Axios, Vite |
| Backend | Java 21, Spring Boot 3.4.2, Spring Security, Spring Data JPA, Maven |
| БД | PostgreSQL в рабочем окружении, H2 для локальной разработки и тестов |
| Инструменты | GitHub, GitHub Actions, Postman/Bruno |

Лицензия проекта — MIT.

## 6. Структура проекта

```text
backend/                 Spring Boot REST API
  src/main/java/         код приложения и доменная модель
  src/main/resources/    конфигурация профилей
  src/test/java/         backend-тесты
docs/                    паспорт, API-контракт и UI-flow
.github/workflows/       CI-проверки
frontend/                React SPA (создаёт Frontend Developer)
```

## 7. Карта функций

Полная карта HTTP-интерфейса находится в [api-contract.md](api-contract.md). Контракты экранов добавляются frontend-разработчиком в `docs/ui-flow.md`.

## 8. Состояние инженерных практик

| Практика | Состояние в ЛР №1 |
|---|---|
| Git-flow | `main` защищена, `lab-1` интеграционная, личные ветки — рабочие |
| Code review | Каждый PR требует review второго участника |
| CI | Maven build для backend; frontend workflow добавляет Frontend Developer |
| Issue tracking | Product issue и вопросы контракта ведутся в GitHub Issues |
| Версии | Версии backend-зависимостей закреплены в `backend/pom.xml` |

## 9. Выполнимость и план семестра

| Лабораторная | Результат |
|---|---|
| ЛР 2 | JPA-сущности, миграции, регистрация, JWT, базовый UI |
| ЛР 3 | Каталог комнат, фильтрация, создание и отмена брони |
| ЛР 4 | Кабинет сотрудника, административные решения и комнаты |
| ЛР 5 | Отзывы, валидация, обработка ошибок и тесты |
| ЛР 6 | Интеграция, документация, демонстрация и релиз |

Оценка — 96 часов: по 48 часов на каждого участника. В MVP входят все восемь функций, JWT, UI, API, тесты ключевых правил и CI. За пределами MVP: уведомления, внешние календари, изображения комнат, аналитика и поддержка нескольких коворкингов.

| Риск | Вероятность | Последствие | Снижение |
|---|---:|---|---|
| Пересечение бронирований | Средняя | Высокое | Серверная проверка интервалов и интеграционные тесты |
| Несовпадение UI и API | Средняя | Среднее | Версионируемый API-контракт и взаимное review |
| Разные локальные окружения | Низкая | Среднее | Фиксированные версии, H2 и CI |
| Задержка review | Средняя | Среднее | Маленькие PR и review в течение одного дня |
