# Coworking Room Booking System

Система бронирования переговорных комнат коворкинга. Сотрудники ищут доступные комнаты и создают заявки; администратор управляет комнатами и подтверждает либо отклоняет брони.

## Предварительные требования

- Docker Desktop 4+ с запущенным Docker Engine;
- Node.js 22+ и npm 10+ для будущего frontend-модуля.

## Запуск backend

```bash
docker compose up --build
```

Сборка Maven и тесты выполняются внутри Docker-образа; локальные Java и Maven не нужны. Данные H2 сохраняются в Docker volume `backend-h2-data`. Для остановки контейнера используйте `docker compose down`.

## Проверка работоспособности

1. Запустить backend командой выше.
2. Открыть `http://localhost:8080/actuator/health`.
3. Ожидаемый ответ: `{"status":"UP"}`.

## Backend-тесты

Тесты и сборка запускаются в Docker из каталога `backend`:

```powershell
docker build --target test --tag coworking-room-booking-backend:test backend
docker build --tag coworking-room-booking-backend:ci backend
docker compose up --build
```

Стадия `test` выполняет `mvn test`; финальная сборка выполняет `mvn verify`.
