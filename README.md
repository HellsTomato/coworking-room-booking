# Coworking Room Booking System

Система бронирования переговорных комнат коворкинга. Сотрудники ищут доступные комнаты и создают заявки; администратор управляет комнатами и подтверждает либо отклоняет брони.

## Предварительные требования

- Java 21;
- Maven 3.9+;
- Node.js 22+ и npm 10+ для будущего frontend-модуля.

## Запуск backend

```bash
cd backend
mvn spring-boot:run
curl http://localhost:8080/actuator/health
```

При первом запуске используется файловая H2 БД в `backend/data/`. Профиль `test` использует in-memory H2.

## Проверка работоспособности

1. Запустить backend командой выше.
2. Открыть `http://localhost:8080/actuator/health`.
3. Ожидаемый ответ: `{"status":"UP"}`.
